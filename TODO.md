Learn these React basics before touching your API. Build a throwaway counter or a small todo list (you already did a todo app in The Odin Project, so rebuild a tiny one in React) to get comfortable with:

Components: functions that return JSX, which is HTML-looking syntax inside JS. Differences from HTML: className instead of class, and {} to embed JS.
Props: how a parent passes data to a child component.
useState: how a component remembers a value and re-renders when it changes. This is the most important concept in React.
useEffect: how you run code when a component first appears, such as fetching data. You'll need it for /users/me on page load.
